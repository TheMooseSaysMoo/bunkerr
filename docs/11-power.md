# Power equipment

**Stock → power** tracks power banks, power stations, battery backups (UPS), generators, solar panels and battery banks. Each one has reminders to charge or maintain it. Lithium packs slowly lose charge on a shelf, and a generator that never runs won't start when you need it.

## Adding a device

Tap **add device** and pick a type. A sensible first reminder is filled in for you:

| Type | Suggested reminder | Optional extras |
|---|---|---|
| power bank | Top up charge, every 3 months | |
| power station | Charge to 80% and test outlets, every 3 months | full discharge / recharge cycle (6 mo) |
| battery backup (UPS) | Run self-test and check battery, every 3 months | replace battery (3 yr) |
| generator | Run under load 20–30 min, every 3 months | fresh fuel / stabilizer (6 mo), change oil (1 yr), spark plug & air filter (1 yr) |
| solar panel | Clean panels and check cables, every 3 months | |
| battery bank | Check voltage and top up charge, every 3 months | |

Every reminder is yours to change:

- **Repeat every**: tap 1 mo, 3 mo, 6 mo or 1 yr, or type any number of days.
- **Next reminder**: a date you set yourself. It suggests *last done (or today) + the interval*, and you can change it to whatever you like. For example, pick the first Saturday you're home.
- **+ custom** adds any reminder you want. Use **✕** to remove one.

Many generator makers recommend running them monthly. Set the interval to 1 mo if yours does.

## Doing the upkeep

Tap **✓ done** on a reminder. You can record:

- the **charge level** for power banks, stations, UPS units and battery banks (shown next to the name, and amber below 40%),
- the **hour meter** for generators,
- a short note ("ran 25 min on the space heater").

The next reminder is set to *the date you did it + the interval*. Each device keeps a **history** of what was done and when.

## Reminders

- **Dashboard**: the *power upkeep* card lists anything due or due within 7 days.
- **Daily digest** (Discord / ntfy): a *POWER UPKEEP DUE* section lists overdue and due-today items.

Viewers can see power equipment but can't change it.
